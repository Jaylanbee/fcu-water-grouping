# 逢甲大學 115-1 通識核心課程《水水臺灣：美麗人生》
## 期末專題分組與路演抽籤系統 (Capstone Grouping & Roadshow Lottery)

本系統專為逢甲大學《水水臺灣：美麗人生》通識核心課程打造，提供 70 位修課同學即時多人線上協同組隊，以及第 15 週／第 16 週路演報告順序抽籤。

### 🌟 系統特色
1. **Google Cloud 臺灣機房即時同步**：全班 70 人手機、筆電與教室投影螢幕 3 秒無縫同步，零延遲。
2. **多人併發防呆與原子合併**：組長挑選組員時自動過濾已分配學生，絕不重複，多組同時送出不互相覆蓋。
3. **自主組隊 ✕ 缺額智慧隨機補齊**：提供自主挑選、個人手機自選加入，以及未分組同學一鍵均勻分配。
4. **路演報告順序公開透明抽籤**：
   - 1~5 號簽：第 15 週路演（現場驗收 V1.0 原生版本）
   - 6~10 號簽：第 16 週路演（強制揭露 V2.0 迭代對照表，以證據決勝）
